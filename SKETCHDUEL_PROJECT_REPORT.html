🎮 SKETCHDUEL

DRAW. IT GUESSES. NOBODY'S SAFE.

A real-time AI drawing duel for the browser. Project Report & Implementation Guide.

Executive Summary

SketchDuel is a real-time drawing game where players race against an AI opponent (SKETCH-BOT 9000) to draw a secret word before the bot correctly guesses it. Built entirely in vanilla HTML/CSS/JavaScript with no frameworks or build tools, it runs in any modern browser using only a free Gemini API key.

Core Innovation: Unlike static image-analysis tools, SketchDuel's loop is continuous and live — the AI watches every brush stroke appear in real time, narrates its guesses out loud, narrows in on the word exactly like a human player in Pictionary, and does it all with zero setup friction.

Stack: Browser only. No backend, no database, no build step. Deployment: any static host (or localhost).

What SketchDuel Is

Gameplay Flow (DUEL Mode)

  1. Secret Word Reveal Screen: Player sees a random word (with a per-word pixel-art sprite background) and a 3-2-1 countdown.
  2. 60-Second Drawing Round: Player draws on a canvas in yellow/white/cyan/magenta. No submit button. As soon as they start, the AI begins guessing.
  3. Live AI Loop: Every ~3 seconds, the canvas is snapshotted to a clean PNG, sent to Gemini vision API, and the model predicts what's being drawn. Its guess and sarcastic commentary appear in a live feed. The bot remembers wrong guesses so it doesn't repeat itself.
  4. Win Condition: If the AI's guess exactly matches the word (or a fuzzy match), the round ends instantly with pixel confetti, party-horn fanfare, and scoring (100 − seconds + streak bonus). If time expires, the player loses.
  5. 5-Round Match: Repeat for 5 words, escalating difficulty. Final score and leaderboard at the end.

Other Modes:

  • PRACTICE: No timer, no word. Player draws freely; bot just keeps guessing to practice its sight.
  • PARTY: Pass-the-laptop mode. 2–4 players, 3 rounds each. Round-robin scoring and final leaderboard.

Technical Architecture

File Structure

index.html (Landing page / mode select) game.html (Game cabinet) styles.css (740+ lines, 6-color palette) cursors.css (Generated pixel cursors) js/config.js (API key storage, gitignored) js/ai.js (Gemini loop, vision pipeline) js/game.js (State machine, UI wiring) js/draw.js (Canvas drawing engine) js/audio.js (Web Audio synthesis) js/sprite.js (Bot avatar & expressions) js/wordart.js (Sprite library + bg animation) js/words.js (227-word bank, difficulty tiers) js/match.js (Fuzzy word matching) js/confetti.js (Pixel confetti on win) js/cursortrail.js (Cursor trail effect)

Core Data Flow

  1. Draw: User pointer events → canvas drawing (coalesced, incremental rendering)
  2. Snapshot: Canvas normalized to black-on-white 512px PNG, base64 encoded
  3. Send: PNG + prompt + wrong-guess history → Gemini vision API (gemini-3.5-flash-lite)
  4. Receive: JSON response { guess, confidence, reaction, is_giving_up }
  5. Match: Fuzzy compare guess vs. word (case/plural/spacing insensitive)
  6. Display: Guess bubble + bot reaction in feed. If exact match → win round.
  7. Loop: Repeat every 3 seconds (configurable) while round is active.

Defensive AI Handling

  • Strict JSON mode: responseMimeType: "application/json"
  • One-retry on malformed JSON (strip markdown, regex extract)
  • Exponential backoff on API errors (2.5s → 5s → 10s → 20s)
  • Graceful degradation: missing key = friendly "AI TEMPORARILY UNAVAILABLE" in UI, real error in console only
  • Never more than one request in flight; skip frames if model is slow
  • Change detection: revision hash prevents duplicate calls on unchanged canvas

Key Features Implemented

1. Real-Time Drawing Canvas

  • Pointer events with coalesced points for smooth, lag-free ink
  • Quadratic Bézier curves through stroke midpoints
  • Incremental segment rendering (only new part redraws while pen is down)
  • 4 ink colors (yellow, white, cyan, magenta) + 3 brush sizes (3/6/12px)
  • Eraser (destination-out composite), Undo, Clear, DPR-aware sizing

2. AI Vision Loop (Gemini 3.5-Flash-Lite)

  • Model: gemini-3.5-flash-lite (non-thinking, fast, generous free tier)
  • Snapshot pipeline: black ink on white, 512px PNG, ~10–30 KB payload
  • Prompt: 450-word system message + inline vision + wrong-guess history
  • Output: strict JSON {guess, confidence, reaction, is_giving_up}
  • Interval: 3 seconds (overridable via config), skipped if no change

3. Fuzzy Word Matching

  • Case/punctuation/article-insensitive matching
  • Plural-aware ("volcanoes" wins "volcano")
  • Spacing-insensitive ("blackhole" matches "black hole")
  • Compound tokens (icecream, hotdog, trafficlight)
  • Synonyms (25+ mapped: tv→television, fridge→refrigerator, etc.)
  • Typo-distance near-misses ask player to rule (Y/N confirmation)

4. Word Bank (227 Total Words)

DifficultyCountWeights
Easy10170% early, 60% overall
Medium9730% early, 40% overall
Hard290% early, post-round 3

Tier-weighted selection with full-cycle exhaustion: never repeats until all words in a tier are used, then auto-resets.

5. Word-Reveal Screen Art

  • 14 hand-authored 12×12 pixel sprites (duck, ghost, star, house, tree, etc.)
  • Procedural generator (seeded by word hash) for unmapped words
  • Tiled animated background: alternating row scroll + stepped sine-wave bob
  • Sprite icons flanking the word (right one mirrored)
  • [TAB] skips word and regenerates entire pattern in place
  • Settings: scrollSpeed, spriteScale, tileGap, opacity (tunable)

6. Arcade Aesthetics (Pixel-Perfect)

  • Locked 6-color palette: #ffd400 (yellow), #000000 (black), #8a7500 (dim), #f2f2e9 (white), #131310 (charcoal), #ff2d55 (alert red, only last 10s + errors)
  • Fonts: Press Start 2P (headlines), VT323 (body)
  • Pixel-notched borders: hard box-shadows (0/-3px left/right, -/+3px top/bottom)
  • Hazard-stripe headers: 45° repeating gradient + animated marquee
  • CRT effects: scanlines (2px/4px, ~9% opacity) + radial vignette
  • Motion: steps() keyframes (no easing), pixel-stepped animations
  • Respects prefers-reduced-motion (skips animations, static renders)

7. Bot Personality (SKETCH-BOT 9000)

  • Washed-up arcade AI: sarcastic, savage, darkly funny
  • Roasts the drawing skill: references actual shapes on canvas
  • Bosses player: "give it legs", "finish it", "add detail"
  • Gloats on wins, despairs on unreadable scribbles
  • 7 expression frames: idle, blink, scan (with radar sweep), confident, celebrate, slump, trophy
  • Auto-blink scheduler with random intervals
  • Voices: system TTS (any OS voice), hover-preview with intro

8. Win Moment Experience

  • Pixel confetti burst: 160 chunky squares in palette colors, two-wave timing
  • Party-horn fanfare: 5-note rise + gliding horn down + confetti pops
  • Arcade stamp: "IT GUESSED IT!" + word + time + points
  • Screen shake + flicker for arcade cabinet feel

9. Custom Cursors & Trail

  • Native cursors: Black pixel arrow (default) + yellow-edge (clickable) + crosshair (canvas), all SVG data-URIs, GPU-composited, zero JS lag
  • Pixel trail: Black squares fade behind pointer, RAF-paced, skips sketchpad, honors reduced-motion

10. Redesigned Menu

  • SKETCH-BOT 9000 mascot beside title (bobbing + blinking)
  • Framed "◄ SELECT MODE ►" panel with hazard header
  • Animated sprite backdrop (faint tiled bots scrolling + bobbing)
  • Scrolling attract marquee at bottom with arcade one-liners
  • No technical status visible to players (clean demo)

Recent Fixes & Optimizations

Quota Crisis Resolution

Problem: gemini-3.5-flash capped at 20 requests/day on user's key — one 60-second round (~24 requests) drained the entire daily quota, leaving "SIGNAL LOST" for all subsequent guesses.

Solution: Probed all available models. Found gemini-3.5-flash-lite (non-thinking, fast, generous quota) as the working alternative. Switched default model and made thinkingConfig conditional (only for thinking models; lite models reject it with 400 error).

Result: Full 5-round matches now run within daily limits with room for heavy demoing.

Browser Caching

Issue: Old cached CSS/JS files persist after updates; users see stale UI.

Fix: Restart server with cache disabled: npx http-server -p 8080 -c-1 or use python -m http.server. Users do Ctrl+F5 on first load.

Thinking Model Truncation

Problem: gemini-3.5-flash (thinking model) was truncating JSON responses mid-object — spent entire token budget on hidden reasoning.

Fix: Added thinkingConfig: { thinkingBudget: 0 } (for thinking models only) + increased maxOutputTokens to 1000.

Deployment & Setup

For a Judge/Demo

  1. Get free API key: aistudio.google.com → Get API Key
  2. Paste into js/config.js:
    window.SKETCHDUEL_CONFIG = { GEMINI_API_KEY: "your-key" };
  3. Serve folder: npx http-server -p 8080 -c-1 (or Python HTTP server)
  4. Open http://localhost:8080 → Play
  5. No visible setup to judges. Open → PLAY → DRAW.

Key Configuration (Optional)

window.SKETCHDUEL_CONFIG = { GEMINI_API_KEY: "your-key", GEMINI_MODEL: "gemini-3.5-flash-lite", // or override GEMINI_INTERVAL_MS: 3000 // snapshot cadence };

Developer Mode

game.html?dev=true or Ctrl+Shift+D in-game → CONFIG drawer (key override, voice test, link check).

Demo Previews

  • game.html?mode=duel → Start DUEL match
  • game.html?screen=game → In-round example (with sample guesses)
  • game.html?screen=word&word=duck → Force word-reveal screen for a specific word
  • game.html?screen=results → Sample end-of-round screen

Loop efficiency ~1 request per 3 seconds (change-detected)

Bundle size ~150 KB total (JS + CSS + cursors, uncompressed)
First page load <2s on modern connection

Failure Recovery: All AI failures degrade in-game with exponential backoff and friendly messaging. Round keeps running. Console logs real errors (silently to avoid alarming judges).

Brainstorm: Future Enhancements

Gameplay Ideas

🔥 Difficulty Ramp: Introduce "Sketchy Mode" where players draw with fewer/smaller strokes (only 3 lines allowed). Forces extreme simplification, makes AI guessing much harder. Unlocks after round 2, higher point multiplier.
⏱️ Speed Challenges: "Blitz Rounds" — 30-second rounds with a 5-point bonus per second remaining. Rewards fast drawing + quick AI recognition.
🎭 AI Personalities: Unlock alternate bot voices/personas after wins. E.g., "Brutally Honest", "Encouraging Coach", "Game Show Host". Each with unique trash-talk style.
📊 Leaderboard Persistence: Use localStorage to store player names/scores across sessions. Show a session leaderboard that persists across tab reloads.
🎨 Custom Color Themes: Unlock alternate color palettes (neon, retro, pastel) based on streaks/wins. Toggle in CONFIG.
🔔 Sound Pack Variety: Unlock different arcade sound packs (chiptune, 8-bit synth, 16-bit console). All still synthesized, no files.

Technical Ideas

🌐 Multiplayer: WebSocket-based real-time duals against a remote player (not AI). Sync canvas + guesses, race to finish in parallel.
🎥 Replay System: Auto-record all rounds (stroke replay via exportStrokes), let players watch replays or share clips.
📱 Mobile Optimization: Touch-friendly UI, adjusted brush sizes for finger input, portrait-mode layout.
🧠 AI Training Feedback: Let players rate bot guesses (right/wrong/close), feed back into a user-hosted fine-tune dataset for future improvements.
🎪 Analytics Dashboard: Dev mode shows stats: total guesses, avg. guess time, most-guessed words, hardest-to-guess words, player accuracy curve.
🎯 Word Difficulty Tuning: Auto-adjust word selection based on round outcomes. If players are crushing easy words, bump up medium earlier.

UX/Polish Ideas

✨ Hover Previews: Buttons show what the action does (e.g., hover "ERASER" → canvas shows eraser cursor, previews erasing).
🎬 Transition Animations: Screen-to-screen slide-ins, scaled reveals (currently: instant). Snappy but visceral.
📢 Chat-Style Guesses: Each bot guess slides in from the right like a chat message, with a small avatar sticker. More immersive.
🏆 Unlockable Achievements: Badges for milestones (5-streak, sub-10s guess, all hard words, etc.). Visible in results screen.
📸 Screenshot Mode: On-win, generate a shareable image (canvas + stats + bot reaction) that players can post to social.

Code Quality & Maintainability

  • No frameworks: Vanilla JS only. Zero dependencies. Easy to fork, customize, or teach from.
  • Modular structure: 10+ single-purpose JS files. Each exports one global namespace (e.g., SD.draw, SD.audio, SD.ai).
  • Defensive coding: All external I/O (Gemini, canvas, DOM) wrapped in try-catch or graceful fallbacks.
  • Responsive: Flexbox layout, relative sizing, handles 640px–2560px widths cleanly.
  • Accessible: Semantic HTML, aria labels, keyboard navigation (Enter/Esc/Tab), respects system preferences (prefers-reduced-motion, prefers-color-scheme if extended).
  • No console spam: Real errors go to console (for devs only). Players see only friendly messages.

Security & Privacy Notes

  • API Key Storage: Lives only in js/config.js, never sent to any server except Google. Gitignored.
  • Game State: Stored in JS memory only. No localStorage, no cookies, no server.
  • Canvas Data: Never persisted locally. Snapshots are sent to Gemini for guessing, then discarded.
  • No Tracking: No analytics, no telemetry, no third-party scripts.
  • Offline Mode: If Gemini is unavailable, game still runs; just shows "AI TEMPORARILY UNAVAILABLE".
  • Post-Hackathon Cleanup: Rotate or delete the API key at aistudio.google.com after judging.
